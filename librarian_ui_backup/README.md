# Librarian UI Backup Archive
Created on: 2026-09-10

This folder contains a complete snapshot of the original Librarian / Admin interface before redesigning the new UI.

## Contents:
- **`views/`**:
  - `admin.ejs`: Main Librarian Portal dashboard, navigation drawer, statistics, modals, and management tabs.
  - `admin_acquisitions.ejs`: Book procurement and vendor acquisitions interface.
  - `admin_review.ejs`: Student book review & rating moderation panel.
  - `admin_settings.ejs`: Library configuration, loan duration, fine rules, and school profile.

- **`templates/`**:
  - `admin.html`, `admin_acquisitions.html`, `admin_review.html`, `admin_settings.html`, `demo_admin.html`: Standalone / static HTML template versions.

- **`static/`**:
  - `coursera-librika.css`: Main UI design system stylesheet (Coursera/Enterprise theme).
  - `live-studio.css`: Video studio & interactive classroom stylesheet.
